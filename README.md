# Battleship Java

A console-based implementation of the classic Battleship game developed in Java using object-oriented programming.

## Features

- 10x10 game board
- Player vs. computer
- Manual ship placement
- Ship placement validation
- Horizontal and vertical ships
- Hit and miss detection
- Hidden opponent ships
- Random computer ship placement
- Computer opponent with random shooting
- Win detection

## Technologies

- Java
- Object-Oriented Programming
- 2D Arrays
- Scanner
- Random
- Eclipse IDE

## What I Practiced 

Through this project, I practiced:

- Object-oriented programming
- Working with classes and objects
- Constructors
- Methods and parameters
- Two-dimensional arrays
- Loops and conditions
- Input validation
- Game logic
- Randomized computer behavior

## How to Run

1. Clone or download the repository.
2. Open the project in a Java IDE such as Eclipse.
3. Run `SchiffeVersenken.java`.
4. Follow the instructions in the console to place your ships and play against the computer.
